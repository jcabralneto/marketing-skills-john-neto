# Matriz de personalização

Expresse as regras como SE condição, ENTÃO ação, EXCETO supressão. Dê prioridade primeiro às condições de impedimento e suporte que tornem inadequado insistir numa oferta. Defina chave de identidade e janela de deduplicação quando o desenho passar para automação.

No curso, NBX conecta sinais → previsão → decisão → entrega → aprendizado. Uma previsão não é obrigatória para começar: registre explicitamente quando se usa uma regra baseada em hipótese. O objetivo é uma experiência relevante e avaliada, não o máximo de mensagens.

A ficha de simulação registra entrada, regra acionada, ação esperada, ação observada e divergência. O teste precisa incluir “nenhuma ação”. Um fluxo que sempre vende, inclusive diante de dados faltantes ou reclamação, não está pronto para ativação.
