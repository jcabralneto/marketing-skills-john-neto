# Contrato de um fluxo

| Elemento | Especificação |
| --- | --- |
| Finalidade | Qual trabalho e decisão o fluxo atende |
| Origem e destino | Sistema de referência, campos necessários e identificador |
| Gatilho | Evento, condição e janela; como tratar eventos atrasados |
| Decisão | Regra/modelo, versão, limite e alternativa manual |
| Ação | O que pode ler, preparar ou alterar no escopo autorizado |
| Duplicação | Chave de idempotência ou deduplicação e retenção aplicável |
| Erro | Tentativas limitadas, condição de parada e reconciliação |
| Confirmação | Evidência nativa de que o destino recebeu a operação |
| Responsável | Quem mantém, revisa e interrompe |
| Medida | Baseline, resultado, prazo, qualidade e custo do mesmo período |

Camadas: dados → sistemas de registro → integração → IA → trabalho de marketing. Permissões, responsabilidade e evidências atravessam todas.

No cálculo econômico, atribua benefício apenas ao que foi medido ou apresente cenário explicitamente estimado. Tempo liberado tem valor de capacidade, mas pode não reduzir desembolso. Receita adicional precisa de margem e suporte de incrementalidade para entrar como benefício econômico atribuível. Valores ausentes ficam ausentes.

O curso compara API, conector e MCP como opções de integração. Essa classificação não informa, por si, quais ferramentas estão disponíveis nesta sessão ou quais permissões a conta concedeu; confira o ambiente real.
