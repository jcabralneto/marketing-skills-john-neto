# 11 skills de marketing — John Neto

Um kit de instruções para usar IA em tarefas de marketing: entender o público, planejar conteúdo, melhorar a presença nas buscas e avaliar resultados.

**[Baixar as 11 skills em ZIP](https://github.com/jcabralneto/marketing-skills-john-neto/releases/latest/download/11-skills-marketing-john-neto.zip)** · [Ler o guia de uso](LEIA-ME.md)

## Comece aqui

1. Baixe e extraia o ZIP. Você não precisa criar uma conta no GitHub para baixar.
2. Abra o arquivo `LEIA-ME.md` e escolha uma skill pela tarefa que quer resolver.
3. Forneça o contexto do seu negócio e os dados disponíveis. Revise a resposta antes de aplicar.

Se seu assistente aceita arquivos, você pode fornecer o `SKILL.md` escolhido e as referências necessárias da mesma pasta como orientação. Em ambientes com suporte a skills, siga a instalação descrita no guia. O pacote inclui um instalador opcional para Codex, com verificação de conflitos.

## Um pedido para começar

> Use marketing-orquestrador para organizar o marketing deste negócio. Minha oferta é [...], quero alcançar [...] e tenho [...] de capacidade. Estes são os dados disponíveis: [...]. Escolha as especialidades necessárias e separe fatos, hipóteses e perguntas.

As skills orientam o assistente; as ferramentas disponíveis e os dados fornecidos determinam o que ele consegue executar. O guia traz outros exemplos e critérios para revisar as respostas.

## Sobre o material

Desenvolvi este pacote depois do curso presencial de IA e marketing que fiz em Harvard, combinando os estudos com critérios de aplicação e revisão. É um material autoral, sem afiliação ou endosso institucional.

As apresentações, gravações, transcrições e o caderno do curso permanecem privados e não integram este repositório nem o ZIP. As referências de origem identificam as fontes sem conceder acesso ao acervo do curso.

As versões para download ficam em [Releases](https://github.com/jcabralneto/marketing-skills-john-neto/releases). O arquivo `MANIFESTO-SHA256.json` permite conferir a integridade dos arquivos do pacote.
